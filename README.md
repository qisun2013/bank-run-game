# bank-run-game

a game of bank run

## Quick start

1. Open `app.py` and set a secure teacher key:
   - `TEACHER_KEY = "your-secret-key"`
2. Start the app:
   - `python app.py`
3. Open links:
   - Student page: `http://<host>:8000/`
   - Teacher page: `http://<host>:8000/teacher?key=<your-secret-key>`

If `TEACHER_KEY` is still `CHANGE_ME_TO_SOMETHING_SECRET`, you must use that exact value in the URL query string or update it before running.
